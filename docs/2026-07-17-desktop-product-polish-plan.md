# AIEverything 0.4 桌面产品化实施记录

## 目标

把 0.3 的可用桌面 MVP 提升为普通用户可以长期使用的独立产品，同时保持局部正文索引、纯本机处理和可选 Agent 连接器边界。

## 已实施

1. 统一桌面视觉体系，增加首次使用、无目录、无结果和后台索引状态反馈。
2. 输入停止 320 ms 后自动搜索；新查询会取消旧的 UI 请求。
3. 增加综合/文件名/正文模式，以及文件类型、修改时间和授权目录筛选。
4. 增加打开文件、资源管理器定位、复制路径、快捷键和单实例启动。
5. 记住窗口大小与常用筛选，不保存搜索关键词。
6. 修复 32 位 NSIS 无法可靠停止 64 位 Daemon 的卸载问题。
7. 同步独立安装包、便携包及可选 Plugin/Skill 到 0.4.0。
8. 将管理后台式双栏改为 Everything 风格的紧凑搜索工具：默认 900×560、索引侧栏默认收起、`Ctrl+I` 切换，并在 175% DPI 下完成真实窗口复验。

## 验收

- 独立启动时自动拉起同目录 Daemon。
- Everything 未连接时，综合搜索降级到局部正文结果。
- UI 自动输入后出现真实结果，复制路径指向存在的文件。
- 第二次启动退出码为 0，系统中只保留一个桌面实例。
- 安装、启动、卸载后目录、进程、注册表和快捷方式无残留；用户正文数据库保留。
- 非环境依赖测试、Plugin/Skill 校验、依赖漏洞检查和发布包内容检查通过。
- 真实发布版在 1080p、175% DPI 下显示为 900×560 逻辑尺寸；索引侧栏展开后目录项仍完整可见。
