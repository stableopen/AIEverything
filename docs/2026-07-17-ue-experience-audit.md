# AIEverything 0.4 UE 体验审计

日期：2026-07-17
视角：不懂技术的普通 Windows 用户
对象：`dist/standalone/win-x64/AIEverything.exe`

## 结论

独立应用的主路径已经可用：用户能理解“只索引主动添加的目录”，Everything 未连接时仍能通过默认综合模式搜索正文，搜索、筛选、打开、定位、复制路径和偏好恢复形成闭环。第二轮进一步将产品收敛为类似 Everything 的小工具：主窗口默认只突出搜索和结果，索引管理按需展开。

## 真实体验证据

- 从发布目录启动 `AIEverything.exe`，主窗口可响应，同时自动启动同目录的 `AIEverything.Daemon.exe`。
- 首屏明确显示当前授权目录、文档/队列/失败数量；Everything 未连接时显示“文件名搜索不可用，正文搜索仍可使用”。
- 通过系统文件夹选择器执行添加目录操作。重复选择已有目录时，旧版本会再次显示“目录已授权”，但根数量不变；这是本轮修复问题之一。
- 使用同一运行中 Daemon 的管理接口加入隔离目录后，状态从“文档 5”变为“队列 1”，随后为“文档 6 · 队列 0 · 失败 0”。
- 在界面选择隔离目录并输入唯一词 `UE-AIEverything-74291`，自动综合搜索返回 1 项，耗时 69.9 ms；Everything 当时未连接，结果来自正文索引。
- 将文件类型切换为 PDF 后显示“没有找到匹配结果”；切回“文本与笔记”后恢复 1 项，证明无结果态与筛选重搜有效。
- 点击“复制路径”后，剪贴板得到实际存在的测试文件完整路径，界面显示成功反馈；测试后恢复了原剪贴板文本。
- 点击“定位”后，Windows 资源管理器实际打开隔离目录，Shell 窗口 URL 与测试目录一致；测试窗口随后关闭。
- 点击“打开”后应用未报错并显示“已打开：ue-search.txt”。
- 关闭重开后恢复“综合搜索 / 全部类型 / 全部时间 / 原授权目录”，搜索框为空，确认不会保存查询词。
- 第二次启动发布版进程以退出码 0 结束，桌面上仍只有 1 个 AIEverything 主窗口。
- 测试结束后已移除隔离索引根、删除测试文件，并停止本轮启动的 AIEverything 进程；用户原有授权根未改动。

## 已修复问题

### P1：重复添加已有目录时成功提示误导

旧行为：Daemon 对重复添加执行幂等返回，桌面仍统一提示“目录已授权”，用户会等待一个实际上不会发生的新索引过程。

修复：提交添加前对规范化路径进行不区分大小写的精确比较。已存在时选择该目录并提示“此目录已在索引列表中，无需重复添加”。

### P1：添加或移除目录后当前搜索不会刷新

旧行为：目录管理期间 `_managementBusy` 为真，原代码在解除忙状态前调用 `ScheduleSearch()`，调用会被直接忽略，结果和目录筛选可能不一致。

修复：仅在管理成功后设置刷新标记，先解除忙状态，再重新调度当前查询。

### P1：快速输入或切换筛选时旧搜索可能回写

旧行为：新的 320 ms 防抖计时开始时并未立即取消正在执行的查询；旧查询可在新查询启动前短暂覆盖结果区。

修复：每次非空查询或筛选变化开始防抖时，立即增加搜索序列并取消当前请求；过期响应不能再渲染。

## 同步调整

- `DesktopPreferences.Default` 最终同步为小工具首屏尺寸 900×560，合法最小尺寸为 820×520；该值经过 1080p、175% DPI 的真实发布版复验。
- 新增 `IndexPanelOpen` 偏好，默认 `false`；旧版设置没有该字段时也安全回落为关闭。
- 索引侧栏关闭时宽度为 0 且不参与布局，展开宽度为 292；欢迎态“添加第一个目录”仍直接打开系统文件夹选择器。
- 顶栏按钮显示“索引目录 / 收起索引”，并为辅助工具暴露“已收起 / 已展开”状态；Ctrl+I 可随时切换。
- 查询词仍不保存。

## 第二轮真实交互证据

- 使用刚编译的 Release 应用打开旧版偏好（缺少 `IndexPanelOpen`），侧栏默认关闭；按钮的 UI Automation 名称为“打开索引目录管理”，状态为“已收起”。
- 点击按钮后变为“收起索引目录管理 / 已展开”，索引管理内容出现，搜索结果区仍是主区域。
- 聚焦搜索框后按 Ctrl+I，按钮恢复“打开索引目录管理 / 已收起”，快捷键生效。
- 展开后关闭应用，设置文件写入 `IndexPanelOpen: true`；重开后按钮状态为“已展开”，证明偏好持久化生效。
- 测试结束前通过 Ctrl+I 恢复关闭并再次退出，最终设置为 `IndexPanelOpen: false`，原授权根保持不变。
- 最终发布版在 168 DPI 上报告 900×560 DIPs；查询“大模型”返回 1 项，按钮展开与 Ctrl+I 收起均通过。压缩状态卡后，展开侧栏中的授权目录项完整可见。

## 后续建议

- UI Automation 当前把根目录项读成内部 record 描述，把结果行读成内部类型名。后续应补 `AutomationProperties.Name`，提升讲述人和键盘辅助工具体验。
- 索引队列只显示数字和不确定进度条。较大目录可增加“已完成 / 待处理”解释与预计阶段，但不建议给无法准确计算的剩余时间。
- “打开”可在文件关联程序启动较慢时提供短暂反馈；当前反馈只能说明 Windows 已接受打开请求。
