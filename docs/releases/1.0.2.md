# AIEverything 1.0.2

打开即可搜索全盘文件名，Word、TXT 和 Markdown 正文会自动在后台加入搜索。

## 下载

- `AIEverything-1.0.2-win-x64.zip`
- `AIEverything-1.0.2-win-x64.zip.sha256`

## 开始使用

1. 下载 ZIP，解压到普通可写目录。
2. 双击 `AIEverything.exe`。文件名搜索立即可用，正文索引自动在后台建立。
3. 输入关键词搜索；右键结果可预览、打开、定位或复制引用。

## 本版更新

- 新安装默认自动启用 `.txt`、`.md`、`.markdown`、`.docx` 正文索引，无需首次确认或添加目录。
- 曾在设置中明确关闭正文索引的用户升级后仍保持关闭；已启用的索引继续复用，不会重复建立数据。
- 首页删除正文启用横幅，只在底部显示简短索引状态；暂停、关闭、同步和异常统计统一放在设置中。
- README 使用新的原生 SVG 展示文件名召回、正文索引、结果净化和智能排序流程。

## 已知限制

- 仅支持 Windows 10/11 x64；便携包尚未代码签名，Windows 可能显示来源提示。
- TXT/Markdown 最大 5 MiB；DOCX 最大 10 MiB；每文件最多 1,000,000 字符且最长处理 15 秒。
- Word 暂不索引页眉页脚、批注、修订、脚注、文本框或嵌入对象，不提供稳定页码，也不会自动跳转到 Word 内命中位置。
- PDF、旧版 DOC、XLSX、PPTX、OCR、邮件和聊天内容不在本版正文范围，但仍可按文件名搜索。
- DeepSeek 歧义增强默认启用，但只有 Windows 凭据管理器中存在凭据且本地歧义门槛满足时才会调用；无凭据时自动使用本地排序。
