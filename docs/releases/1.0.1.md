# AIEverything 1.0.1

像 Everything 一样快速搜索全盘文件名，还能直接找到 Word、TXT 和 Markdown 中的具体段落，并优先展示更可能需要的结果。

## 下载

- `AIEverything-1.0.1-win-x64.zip`
- `AIEverything-1.0.1-win-x64.zip.sha256`

## 三步开始使用

1. 下载 ZIP，解压到普通可写目录。
2. 双击 `AIEverything.exe`；文件名搜索立即可用。
3. 点击“启用正文”，等待 Word、TXT 和 Markdown 正文在后台逐步加入搜索。

## 本版新增

- 正文白名单为 `.txt`、`.md`、`.markdown`、`.docx`。
- DOCX 可搜索标题、普通段落和表格单元格，并显示标题路径、段落或表格坐标。
- 损坏、超大、超时、加密/不支持或无权限文件不会阻塞后续索引；可在设置中查看分类并重试。
- 首页索引状态更简洁，设置中可直接打开反馈页面。

## 已知限制

- 仅支持 Windows 10/11 x64；便携包尚未代码签名，Windows 可能显示来源提示。
- TXT/Markdown 最大 5 MiB；DOCX 最大 10 MiB；每文件最多 1,000,000 字符且最长处理 15 秒。
- Word 暂不索引页眉页脚、批注、修订、脚注、文本框或嵌入对象，不提供稳定页码，也不会自动跳转到 Word 内命中位置。
- PDF、旧版 DOC、XLSX、PPTX、OCR、邮件和聊天内容不在本版正文范围，但仍可按文件名搜索。
- 本地语义重排需要 AVX2；不可用时自动回退，不影响普通搜索。
