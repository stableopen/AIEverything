# AIEverything 独立桌面 MVP 实施计划

## 最终形态

AIEverything 以独立 Windows 桌面软件为主产品。普通用户安装后可选择授权目录，并搜索文件名、路径和文档正文。Codex Plugin 与 Skill 作为可选适配层单独提供，不是桌面软件的运行依赖，也不默认安装。

## 本轮交付

1. 新增 WPF 桌面程序，提供综合、文件名和正文三种搜索模式。
2. 提供授权目录选择、添加、移除、重建以及索引暂停/恢复。
3. 显示索引文档数、队列数、失败数、Everything 状态和查询耗时。
4. 启动桌面程序时确保每用户唯一的正文索引守护进程运行。
5. 生成 Windows x64 自包含发布目录和可安装包，不要求用户安装 .NET SDK。
6. 保留 Plugin/Skill，但改写为调用独立产品能力的可选连接器，并默认不安装。

## 验收标准

- 未运行 Everything 时，桌面程序仍能启动并使用授权目录正文搜索。
- 用户可以通过系统目录选择器添加局部目录，盘符根和系统目录仍由核心策略拒绝。
- 添加测试目录后能看到索引进度，并搜索到 TXT 文档中的唯一正文。
- 发布目录包含桌面程序、Daemon、ExtractorWorker、Everything SDK DLL 和 SQLite 本地库。
- 独立发布物不写入 Codex 配置，不启动 Codex MCP 进程。
- 桌面协调层单元测试、现有非环境依赖测试、发布烟雾测试和差异检查通过。
